# Checklist — Event-driven ingestion & routing

Source of truth: `docs/REQUIREMENTS.md` §4. Topic skills: `agent-starter-background-jobs`.
Status in this area: 13 implemented, 0 partial, 0 gap, 0 deferred.

How to run the checks: `pnpm --filter <package> exec vitest run …` commands run from the agent-starter monorepo root (in a generated project with `--deps vendor`, run them only if you changed `vendor/agent-starter/*`, from that package directory with `npx vitest run …`). Checks marked "generated app" run inside a generated project (in the monorepo: prefix with `pnpm --filter full-stack-agents`). URLs assume `pnpm dev` on `localhost:5173`. Tick an item only after its check passed in this change. Do not tick GAP or PARTIAL items: report them as open in your final summary unless your change closes them.

- [ ] **R-EVT-01** The ingestion worker does zero AI: it verifies the signature on the raw body, validates and sanitizes with zod, attaches tenant and session, enqueues, and answers 202. — verify: `pnpm --filter @agent-starter/cloudflare exec vitest run test/cloudflare.test.ts -t 'accepts valid signed payloads with 202 and enqueues an envelope'` and `pnpm --filter @agent-starter/core exec vitest run test/round3.test.ts -t 'neutralises the four keywords anywhere, mid-sentence and without a colon'`
- [ ] **R-EVT-02** Rejections are structured: unsigned 401, contract violation 400 (`CONTRACT_VALIDATION_FAILED` + issues), missing tenant 401, oversized 413. — verify: `pnpm --filter @agent-starter/cloudflare exec vitest run test/cloudflare.test.ts -t 'rejects unsigned \(401\) and contract-violating \(400\) payloads'` and `pnpm --filter @agent-starter/cloudflare exec vitest run test/round3-edge.test.ts -t 'answers 500 INTERNAL_INGESTION_CRASH as JSON when the enqueue fails|still answers 202 when the enqueue succeeds'`
- [ ] **R-EVT-03** The queue consumer coalesces rapid-fire events per tenant + session into one agent turn (batch 10 / 5 s). — verify: `pnpm --filter @agent-starter/cloudflare exec vitest run test/cloudflare.test.ts -t 'coalesces per session, acks on success, retries on dispatch failure, drops poison pills'` and `pnpm --filter @agent-starter/core exec vitest run test/memory-cognition.test.ts -t 'coalesces rapid events per session and dedupes ids'`
- [ ] **R-EVT-04** Tenant-level rate limits are enforced before an agent wakes (429 at ingest or deferred turns). — verify: `pnpm --filter @agent-starter/cloudflare exec vitest run test/cloudflare.test.ts -t 'defers turns when the tenant is over its rate limit'` and `pnpm --filter @agent-starter/core exec vitest run test/memory-cognition.test.ts -t 'rate limits per tenant with a token bucket'` and `pnpm --filter create-agent-starter exec vitest run test/compose.test.ts -t 'wires background DLQ tooling, job control and tenant rate limits'` and `pnpm --filter @agent-starter/flue exec vitest run test/http-security.test.ts -t 'rate limits chat turns per tenant with 429 \+ retry-after, honouring TenantConfig\.rateLimit'` and `pnpm exec vitest run test/platform.test.ts -t 'keeps edge events and consumer turns in separate rate-limit buckets'` (generated app)
- [ ] **R-EVT-05** Per-message ack/retry with backoff; poison pills are dropped; failures land in a dead-letter queue after max retries. — verify: `pnpm --filter @agent-starter/cloudflare exec vitest run test/cloudflare.test.ts -t 'coalesces per session, acks on success, retries on dispatch failure, drops poison pills'` and `pnpm --filter create-agent-starter exec vitest run test/compose.test.ts -t 'wires queue consumers and crons for background \+ multi-agent'`; every `queues.consumers[]` entry in `wrangler.jsonc` has `max_retries` and `dead_letter_queue`, and `scripts/init-cloudflare-infra.sh` creates each DLQ
- [ ] **R-EVT-06** Deterministic instance-id mapping: event identity (tenant + contact/user/session) maps to the session's open job instance; a finished job hands later events to a fresh job. — verify: `pnpm --filter @agent-starter/flue exec vitest run test/http.test.ts -t 'mints conversations scoped to the caller'`
- [ ] **R-EVT-07** Event-driven wakeup: the coalesced turn is delivered into the (possibly dormant) agent as a signal, with an idempotency key so redeliveries never duplicate work. — verify: `pnpm exec vitest run test/ingestion.e2e.test.ts -t 'accepts a signed event with 202'` (generated app); local smoke: POST a signed event to `/events/app/tenant_dev` (see R-OPS-13) and confirm a `background-worker--tenant_dev--…` run appears in `GET /api/jobs/:id`
- [ ] **R-EVT-08** Sequential processing: events that arrive mid-run are queued and handled after the current turn; concurrent events for one entity never race. — verify: `pnpm --filter @agent-starter/core exec vitest run test/memory-cognition.test.ts -t 'queues mid-run events sequentially without duplicates'`
- [ ] **R-EVT-09** Typed, sanitized provider contracts: Manychat contact events (bounded fields, injection cleansing), generic chat events, Stripe signature verification. — verify: `pnpm --filter @agent-starter/integrations exec vitest run test/webhooks.test.ts -t 'applies defaults and cleanses untrusted fields|cleanses names and rejects out-of-bounds or malformed payloads|rejects tampered bodies, wrong secrets, stale timestamps and malformed headers'` and `pnpm exec vitest run test/background.test.ts -t 'verifies the tenant'` (generated app)
- [ ] **R-EVT-10** Zero-egress delivery: generated documents, reports and logs are written to R2 and referenced by key/URL. — verify: run a background job to REPORT and confirm `save_artifact` returns a `key` that exists in R2 (`npx wrangler r2 object get <bucket>/<key> --local`)
- [ ] **R-EVT-11** Webhooks out: the run ends by POSTing a signed result (with the R2 URL) to the SaaS, with retries and an outbox. — verify: `pnpm --filter @agent-starter/core exec vitest run test/security.test.ts -t 'verifies signed webhooks and rejects tampering and replays'` and `pnpm exec vitest run test/delivery.test.ts -t 'parks a delivery that failed its retries and the cron drain delivers it later, re-signed|keeps retrying with backoff, then marks the row DEAD after 12 attempts|delivers directly when the SaaS answers, and the telemetry sink never throws into the agent'` (generated app); point `PRIMARY_SAAS_WEBHOOK_URL` at a request bin and confirm `job.result` arrives with `x-agent-signature` and `x-tenant-id`
- [ ] **R-EVT-12** Every ingestion route derives the agent session from the event's own identity (conversation / sender / contact) and de-duplicates provider redeliveries by event id. — verify: `pnpm --filter create-agent-starter exec vitest run test/compose.test.ts -t 'wires background DLQ tooling, job control and tenant rate limits'` and `pnpm --filter @agent-starter/cloudflare exec vitest run test/edge-security.test.ts -t 'enqueues a delivery once and answers duplicates with 200'` and `pnpm exec vitest run test/background.test.ts -t 'racing consumers pick the same next job'` (generated app)
- [ ] **R-EVT-13** Artifacts are delivered by signed, expiring download links scoped to the tenant's artifact prefix; the bucket stays private. — verify: `pnpm exec vitest run test/delivery.test.ts -t 'serves the tenant|never signs another tenant'` (generated app)
