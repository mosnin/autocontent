- [ ] **R-PER-01** Opt-in `persistent` module that composes alone and with every module; only an admin (creator role) can create a persistent agent, and the agent has no HTTP mount. — verify: `pnpm --filter create-agent-starter exec vitest run test/compose.test.ts -t 'wires the persistent module: control DO, routes, no HTTP mount for the agent, egress vars and its eval suite'` and `pnpm --filter @agent-starter/cloudflare exec vitest run test/persistent-control.test.ts -t 'requires a session \(401\), a creator role to create \(403\) and owner/admin to manage'`
- [ ] **R-PER-02** The trusted control plane is the only writer of the agent's versioned config; the agent can only propose; narrowing proposals apply after review, widening ones (egress, credentials, budget, frequency, reviewer, skills) need a human; identity, owner, enabled and version are never proposable. — verify: `pnpm --filter @agent-starter/core exec vitest run test/persistent.test.ts -t 'classifies widening proposals as human and narrowing/text ones as auto|never lets a patch change identity, owner, enabled or version|only propose \(source agent\) and store agent memory as untrusted'` and `pnpm --filter @agent-starter/cloudflare exec vitest run test/persistent-control.test.ts -t 'creates a versioned config, applies low-risk changes and parks widening ones as proposals|returns 202 proposals for widening edits, 409 on stale versions, and approves them'`
- [ ] **R-PER-03** Network boundary: a managed egress allowlist plus a default deny list (pastebin, webhook.site, cloud metadata) on top of the SSRF guard; tenant and agent lists only narrow it; every redirect hop and every URL argument is checked. — verify: `pnpm --filter @agent-starter/core exec vitest run test/persistent.test.ts -t 'denies the default deny list and private hosts on top of the allowlist|lets tenant and agent lists only narrow the managed allowlist|checks every redirect hop'` and `pnpm --filter @agent-starter/flue exec vitest run test/hook-persistent.test.ts -t 'caps tool calls per tick and blocks URL arguments outside the egress policy'` and `pnpm exec vitest run test/persistent.test.ts -t 'builds a managed allowlist the agent can only narrow, with the default deny list on top'` (generated app)
- [ ] **R-PER-04** Secrets boundary: a credential broker injects named credentials only for their bound hosts over https; secrets never reach tool arguments, results, the model or logs. — verify: `pnpm --filter @agent-starter/core exec vitest run test/persistent.test.ts -t 'injects the header only for bound hosts and never for unknown names or http|drops caller credential headers and strips the credential on redirect to another host|fetches only allowlisted hosts, injects the brokered credential and scrubs it from output'` and `pnpm exec vitest run test/persistent.test.ts -t 'injects a credential only for hosts both the platform and the agent'` (generated app)
- [ ] **R-PER-05** Auto-review: a second model approves, blocks or escalates every tool call of a persistent agent before it runs; it fails closed and escalations use the human approval flow. — verify: `pnpm --filter @agent-starter/core exec vitest run test/persistent.test.ts -t 'returns the model|fails closed: no model, errors and garbage all escalate|blocks, escalates to approval, or lets approved LOW calls run \(HIGH still needs a human\)'` and `pnpm --filter @agent-starter/flue exec vitest run test/hook-persistent.test.ts -t 'auto-reviews every call: approve runs, block denies, escalate parks for a human'`
- [ ] **R-PER-06** Identity separation: each agent has its own principal acting for its owner, a harness conversation no user can own or seed, and a signed short-lived agent assertion for the host SaaS. — verify: `pnpm --filter @agent-starter/core exec vitest run test/persistent.test.ts -t 'separates the agent principal from the owner and round-trips a signed assertion|rejects the wrong audience, expiry, tampering and replays|names the persistent agent'` and `pnpm --filter @agent-starter/flue exec vitest run test/http-security.test.ts -t 'never lets a user'` and `pnpm exec vitest run test/persistent.test.ts -t 'a client request through agentAuth can neither open the agent'` (generated app)
- [ ] **R-PER-07** Kill switch: disabling an agent stops the alarm, locks render and execution (re-checked live before every tool call), and an unreadable state counts as disabled. — verify: `pnpm --filter @agent-starter/flue exec vitest run test/hook-persistent.test.ts -t 'locks execution when the kill switch flips mid-turn, then locks render on the next tick|treats an unreadable kill switch as disabled'` and `pnpm --filter @agent-starter/cloudflare exec vitest run test/persistent-control.test.ts -t 'the kill switch stops dispatch and the alarm; a lost turn is cleared after the stale window'` and `pnpm --filter @agent-starter/react exec vitest run test/persistent.test.tsx -t 'disables the agent only after confirmation, then offers re-enable'`
- [ ] **R-PER-08** Heartbeat and schedules: a DO alarm (30 min default, 5 min minimum) dispatches the checklist or a named cron schedule as one server-only, idempotent signal; quiet hours defer, one turn runs at a time (skips recorded), `HEARTBEAT_OK` ends a quiet tick, and the tool-call cap and daily budget hold. — verify: `pnpm --filter @agent-starter/cloudflare exec vitest run test/persistent-control.test.ts -t 'dispatches a heartbeat with the checklist and identity, then single-flights and records skips|fires named schedules, defers during quiet hours and stops on the daily budget|records a failed dispatch as an error turn and clears in-flight'` and `pnpm --filter @agent-starter/flue exec vitest run test/hook-persistent.test.ts -t 'handles a heartbeat: HEARTBEAT_OK ends the turn cheaply and reports a summary'` and `pnpm --filter @agent-starter/core exec vitest run test/persistent.test.ts -t 'computes the next fire with steps, lists, day-of-week and time zones|defers ticks inside quiet hours, including windows that span midnight'` and `pnpm exec vitest run test/persistent.test.ts -t 'turns a heartbeat tick into one server-only signal, idempotent per turn, as the agent'` (generated app)
