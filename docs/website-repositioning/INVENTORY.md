# Website inventory and scope

Primary navigation: logo, Product, Solutions, Resources, Company, Pricing. Desktop menus use click/keyboard disclosure with Escape focus return; mobile expanding template menu retains the same destinations. Generic X/LinkedIn links were removed because they are not verified company profiles. Existing paid theme and all source assets are retained.

Product: video creation, search content, ad campaigns, plus substantive pages for video, articles, scheduling, automation, analytics, UGC, dramas, motion, library, templates, channels, campaigns, SEO audit. These describe source-present workflows and prerequisites; they do not certify current provider availability.

Solutions: founders/SaaS, ecommerce, agencies, creators, local businesses, AI agent builders. These are proposed uses, not claims that named customers use Marketer.

Resources: resource hub, guides index, help center, API/docs, quickstart, FAQ, changelog; guides for first channel, article production, agent-driven work, content brief, draft review, and production budgeting. Blog/editorial publishing calendar, Discord/community, events and webinars have no verified offerings; omitted rather than manufactured.

Company: About, Contact, Demo request and Legal. Careers/open roles have no supplied vacancies; no fabricated hiring page. Press requests use the existing contact reason; no fabricated press coverage or media kit. Social profiles await verified destinations. No customer logos or testimonials available for the framework’s proof-strip requirement. Illustrative campaign art is not logo social proof.

Role exceptions: articles use reading structure and in-page navigation; help/index pages use task/category links; contact/demo use forms and next-step explanation; pricing uses commercial comparison and complete terms; legal pages preserve existing policies. Auth/application/onboarding are retained outside this marketing-copy change. Live login, email delivery, subscription billing, onboarding persistence, provider generation and production release are separate verification gates.

New routes: /how-it-works, /demo, /resources/help, /resources/guides, /resources/guides/content-brief, /resources/guides/review-checklist, /resources/guides/plan-content-budget. Existing routes remain accessible and sitemap includes all public marketing pages.

The supplied $300 template is the intended visual identity. No replacement visual direction was introduced. Original orbit, film, gallery, scroll walkthrough, typography, colors, rounded controls and inverted CTA are preserved. Inner-page copy is reorganized around buyer tasks using existing theme primitives. Campaign assets are reused as illustrative media; no claim is made that a new image is a customer result.
